NAT Traversal Problem — aipotluck-local-client

Cloud control plane can't reach a local inference server sitting behind an unpredictable home/office firewall

Cloud side

  • • SvelteKit server, public IP
  • • Accepts inbound connections freely
  • • Wants to route chat requests to a user's machine

The blocker

  • • Firewall/NAT of unknown type
  • • No port-forwarding assumed
  • • No admin router access assumed
  • • Must work "out of the box" for any user

Local side

  • • aipotluck-local-client + llama-server
  • • No public IP, no inbound reachability
  • • Must still stay connected to the cloud

aipotluck-local-client • NAT traversal is an open research question — see research/nat-traversal/nat-traversal-report.md for candidate techniques
